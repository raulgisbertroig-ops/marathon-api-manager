# Marathon API Manager

REST API developed with Java and Spring Boot for managing runners and their training data.

This project was created as part of my backend development learning process, with a focus on understanding how REST APIs communicate with a database and how different application layers interact.

## 🚀 Technologies

- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- Hibernate
- Maven
- MySQL
- Postman

## 🧩 Project structure

The application follows a simple layered structure:

```text
src/main/java/
└── api/
    ├── controller/
    │   └── RunnerController
    ├── model/
    │   └── Runner
    └── repository/
        └── RunnerRepository
